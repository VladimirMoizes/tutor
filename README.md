## Проект: Сайт для репетиторских услуг "Tutor"

**Стек технологий:** React, Redux, TypeScript, Node.js, Express, MongoDB, JWT

**Ссылка на проект:** https://github.com/VladimirMoizes/tutor

**Реализованный функционал:**

### Frontend (React/TypeScript)
- Разработал адаптивный UI-дизайн и интерактивные компоненты
- Настроил клиентскую маршрутизацию с React Router
- Реализовал полностью адаптивную верстку для всех устройств
- Создал пользовательский интерфейс с фокусом на удобство использования
- Интегрировал state-менеджмент Redux Toolkit для управления состоянием приложения

### Backend (Node.js/Express/MongoDB)
- Разработал RESTful API с Express.js для обработки запросов
- Реализовал систему аутентификации с JWT токенами
- Настроил безопасное хранение паролей с bcrypt
- Создал модели данных с Mongoose ODM для MongoDB
- Реализовал middleware для защиты маршрутов

### Функционал аутентификации и авторизации
- **Регистрация пользователей** - валидация данных, создание аккаунта, генерация JWT
- **Вход в систему** - проверка учетных данных, выдача токена
- **Защищенные маршруты** - middleware для проверки авторизации
- **Выход из системы** - очистка токена и состояния
- **Обновление профиля** - редактирование личных данных
- **Удаление аккаунта** - безопасное удаление с подтверждением пароля

### Безопасность и валидация
- Валидация входных данных на клиенте и сервере
- Защита от неавторизованного доступа к API
- Безопасное хранение токенов в localStorage
- Обработка ошибок и исключительных ситуаций

### Особенности реализации
- TypeScript для типобезопасности на фронтенде и бэкенде
- Redux Toolkit для эффективного управления состоянием
- Модульная архитектура компонентов и API
- Responsive дизайн с поддержкой мобильных устройств
- Интуитивный пользовательский интерфейс с модальными окнами

 **Инструкция по запуску:**
```bash
# Клонирование репозитория
git clone https://github.com/VladimirMoizes/tutor.git
cd tutor

# Установка зависимостей
npm install

# Запуск backend сервера (в первом терминале)
node server.js

# Запуск frontend приложения (во втором терминале)
npm run dev
